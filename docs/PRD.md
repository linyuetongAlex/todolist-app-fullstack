# 项目背景/目标
一个待办事项应用,帮助用户高效管理日常任务

# 用户角色
普通用户: 普通用户,需要登录才能使用应用。
游客模式: 未登录用户,只能查看应用的公开内容,不能进行任务管理操作。

# 核心用户故事
普通用户: 作为一个普通用户,我想要能够登录应用,以便创建、更改、查看、删除我的任务。并且可以查看任务的详细信息，设置任务的优先级和截止时间，可以查看任务的统计信息,包括已完成任务数、未完成任务数。
游客模式: 作为一个游客模式用户,我想要能够查看应用的公开内容,以便了解应用的功能。并且可以注册账号,以便登录应用。

# 功能需求列表
P0：
- 登录功能: 用户可以通过输入用户名和密码登录应用。
- 登录后,用户可以查看和更改自己的任务。
- 登录后,用户可以添加、删除和完成任务。

P1：
- 用户可以查看任务的分页列表,每页显示10个任务，任务的排序按照添加的时间顺序
- 用户可以查看任务的详细信息,包括任务的创建时间、完成时间、状态等。
- 用户可以设置任务的优先级和截止时间。
- 游客模式用户可以注册账号

P2：
- 用户可以查看任务的统计信息看板，可以看到daily（在首页显示今日完成xx个任务）/weekly（柱状图）/monthly（折线图）的统计数据。
- 用户可以按照添加的时间顺序/任务优先级展示首页的任务,还可以选择回到原本的展示。
- 已完成的任务会呈现"划掉的标题+复选框"的视觉，然后自动沉底，沉底的任务按照完成时间的先后展示
- 超过deadline时间的任务，会自动变灰，可以选择编辑延长过期时间。




# 非功能需求
- 密码必须加密存储,不能明文存储。
- 用户的账号必须是唯一的,不能重复注册。
- 用户密码必须符合一定的复杂度要求,如包含字母、数字和特殊字符等。

# 验收标准
- 登录后,用户可以查看已完成任务列表,包括已完成任务的详细信息,如任务的创建时间、完成时间、状态等。
- 增加任务后,任务会立即显示在todo列表界面
- 删除任务后,任务会立即从todo列表界面移除
- 完成任务后,任务会立即从todo列表界面移除,并添加到已完成任务列表
- 编辑任务标题后,列表要立即刷新
- 登录时密码错误,要提示用户重新输入。
- 登录时用户名不存在,要提示用户重新输入。
